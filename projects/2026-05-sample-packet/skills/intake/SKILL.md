# Side Project Intake Skill

Use this skill when capturing a new rough side-project idea.

## Goal

Create a durable project packet that preserves the user's raw idea while adding enough inferred structure for future discovery.

## Instructions

1. Preserve the user's original wording in `spec/idea.md`.
2. Add an interpreted intent section that is practical and clearly marked as inference.
3. Record assumptions and open questions in `workflow/status.yaml`.
4. Set the stage to `idea` if the direction is still vague, or `discovery` if the next useful action is refinement.
5. Append a short entry to `THREAD_LOG.md`.

## Guardrails

- Do not start implementation from a fuzzy idea.
- Do not bury durable context only in chat.
- Keep the packet runner-agnostic unless the user explicitly chooses a runner.
