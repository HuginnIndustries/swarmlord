# Side Project Discovery Skill

Use this skill when refining a fuzzy idea into a practical project direction.

## Goal

Turn a rough idea into a clear project option set, recommendation, and path toward a build-ready spec.

## Instructions

1. Read `spec/idea.md` and `workflow/status.yaml`.
2. Clarify goal, audience, constraints, success criteria, and non-goals.
3. Compare meaningful options when the direction is ambiguous.
4. Recommend an MVP and explain why it is the best next step.
5. Update open questions and assumptions in `workflow/status.yaml`.

## Output

Write durable findings to `spec/discovery.md`.

## Guardrails

- Prefer questions for high-impact product choices.
- Infer generously for low-risk details and mark assumptions.
- Do not write implementation code during discovery.
