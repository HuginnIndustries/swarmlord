# Side Project Extraction Skill

Use this skill when preparing a project packet to move into its own repository.

## Goal

Preserve the useful planning context while creating a clean standalone repo handoff.

## Instructions

1. Confirm `spec/build-spec.md` is complete enough to guide implementation.
2. Review `EXTRACT.md` and update it with project-specific steps.
3. Ensure local `skills/`, `workflow/`, and `THREAD_LOG.md` are useful outside the parent repo.
4. Update `workflow/status.yaml` and root `projects/INDEX.md` after extraction.

## Guardrails

- Do not delete the original packet unless explicitly asked.
- Do not extract unresolved foundational choices as if they were settled.
